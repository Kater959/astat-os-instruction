# ASTAT OS · инструкция-показ

Портативный HTML: камера ходит по **реальным снимкам** рабочих экранов. Геометрию цеха мы не рисовали.

## Открыть

Из этой папки:

```bash
python3 -m http.server 4055
```

Затем откройте http://127.0.0.1:4055/ — если сервер запущен из этой папки. Если из каталога «АСТАТ»: http://127.0.0.1:4055/astat-os-instruction/

Файл `index.html` можно открыть и просто с диска; картинки — относительные (`media/…`).

## Как смотреть

- **Шаги** (по умолчанию) — как инструкция: стрелки, «Дальше», пробел.
- **Показ** — автопрогон ~8 с на кадр.
- Клавиши: `P` показ, `S` шаги, `Esc` в начало.

Если в системе включено «уменьшить движение», камера не летает: только смена кадра.

## Состав

- `index.html` — сцена, режимы, текст
- `media/*.jpg` — кадры 10.09.2026
- `media/source/*.png` — мастера
- `EVIDENCE.md` — что кадр доказывает, а что нет

Не кладите этот пакет на публичный хост без отдельного согласия: на кадрах демо-клиенты каталога и стол директора.
